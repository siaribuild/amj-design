# Domain docs

Single-context repo.

- **Glossary**: `CONTEXT.md` at the repo root — the canonical domain language. Read it before speccing, designing, or naming anything; it is a glossary only, never a spec or scratchpad. The architect owns it.
- **ADRs**: `docs/adr/` (create on first ADR). An ADR is warranted only when a decision is hard to reverse, surprising without context, AND the result of a real trade-off — all three, or skip it.
